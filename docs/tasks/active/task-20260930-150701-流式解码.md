## 🎨 方案设计

### 最终选择（用户已确认，2026-09-30）

新模块 `stream`，全部 `#[non_exhaustive]`：

- `StreamDecoder::new(Protocol)` / `with_stream_id` / `push(&[u8]) -> Vec<StreamEvent>` / `finish()` / `abort()`
- `StreamEvent`：`TextDelta` / `ReasoningDelta` / `ToolUseStart` / `ToolUseDelta` / `Usage` / `Finish` / `Error`
- `StopReason`：`EndTurn` / `ToolUse` / `MaxTokens` / `StopSequence` / `Refusal` / `PauseTurn` / `Other(String)`，有 `as_str` / `parse` / serde
- `StreamOutcome`（字段 `content` = Anthropic 风格 block 数组，另有 `text()`）与 `StreamEnd`：`Complete` / `Truncated` / `Cancelled` / `Failed` / `NotEventStream`
- 纯函数：`is_stream_options_rejected(status, body)`、`looks_like_html(body)`

决策（用户按建议确认）：
1. **`ToolUseStart` 延迟到工具名已知时才发**，名字始终没来则收尾时补发（sigil 现状是块创建即发，名字可能为空）
2. 字段命名按 crate 惯例 **camelCase**，sigil 在薄映射里转
3. Anthropic 流内 `error` 与 OpenAI 统一为终态 `Failed`（sigil 现在只发事件、流继续）
4. **不做**：Ollama NDJSON、`<think>` 标签剥离、cache 用量字段、`diagnose_success` 下沉、max_tokens 超限自愈
5. 块号约定：文字 0，第 k 个工具调用 k+1；Anthropic 用协议自带 `index`

### 调研结论要点

- 六家里只有 sigil 与 knowledge_base 处理 tool_calls；其余四家只做文字流
- prism 不是「一条怪癖都没处理」：它有字节缓冲、`[DONE]`、流内 error、role-only 首块；缺 usage、finish_reason、tool_calls、截断检测、2xx 回网页、`stream_options` 重试
- aibid、onestop 逐块 `from_utf8_lossy` 会乱码；sigil Anthropic 分支只认 `\n\n`；crate 用带残余字节的缓冲统一修掉
- 相对 sigil 新增的怪癖：UTF-8 跨包、`data:` 无空格、多行 data 拼接、`event:` 缺失时按 data 的 `type` 分派、Anthropic 缺 id 补 id、`finish_reason` 为 `""` 跳过、末尾空 choices 的 usage 帧不冲掉 finish_reason、usage 覆盖不累加、单行 JSON 解析失败跳过、多 choices 只读 `[0]`、`reasoning_content` / `thinking_delta` → `ReasoningDelta`

**与方案的差异**（实现中做的取舍）：
- `finish()` 返回 `(Vec<StreamEvent>, StreamOutcome)`：收尾要补发 `ToolUseStart` 与 `Finish`，只返回 outcome 装不下
- `Finish` 事件只在 `Complete` 时于 `finish()` 里发；断流 / 取消 / 出错不发
- `ToolUseStart` 触发条件：名字已知，且（id 已到 或 参数已开始）。「名字先到、id 与参数都没来」时先等
- 新增 `StreamOutcome.reasoning`（累积的思考文字）与 `skipped_frames`（跳过的坏帧数）
- 缺 index 但有 id 时按 id 认块；index 全是 0 但 id 不同时另起一块（sigil 只有按位置算）
- 事件间漏空行：拼起来不是 JSON、每行单独是，则逐行各当一帧
- `is_stream_options_rejected` 同时认 `include_usage`（取 aibid 的做法），状态码仍限 400 / 422（取 sigil 的做法）
