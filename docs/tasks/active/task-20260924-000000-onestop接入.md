### 存量地址修正

- 旧规则（冻结）：去末尾 `/` → 以 `/{path}` 结尾原样 → 地址带路径就直接拼 → **只有主机名才补 `/v1`**

- 判据：对照测试「旧规则(原值) == crate(修正值)」，覆盖对话 / messages / models / embeddings / images / audio 六条路径
- 入口：只有 v16 迁移一处（没有备份 / 同步写回；ai.profile 导入按 crate 语义原样使用）
